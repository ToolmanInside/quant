# 每日中短期趋势模拟系统

## 目标与边界

系统把历史严格分成两个阶段：

- **回测期**：由回测起点和回测终点定义，只评估策略和候选版本，不创建持仓，
  不改变模拟资金。
- **模拟期**：从单独设置的模拟盘起点开始，账户才以初始资金运行。每天收盘后使用
  当日及以前的数据生成下一交易日计划。

回测终点必须早于模拟盘起点。系统只更新本地文本虚拟账户，不连接券商，也不会
发送真实订单。

当前候选池是用户配置的一组股票/ETF，不代表全市场。板块评分也是候选池内的相对
比较；要把它升级为可用于更严肃研究的全市场系统，需要使用历史时点成分股构建股票池，
避免只挑今天仍然存在或事后表现较好的股票。

## 可选日频策略

初始化模拟账户时必须选择一种策略。策略在回测期和模拟期保持一致，修改策略后需要
重新初始化账户，不能在持仓中途悄悄切换。

| 策略 | 买入/入选条件 | 主要退出条件 |
|---|---|---|
| 双均线趋势 | 快均线高于慢均线，并在候选池中排名靠前 | 快均线跌破慢均线 |
| 价格动量 | 20日和60日动量为正，且价格位于短均线上方 | 20日动量转负或跌破短均线 |
| 通道突破 | 收盘突破此前20日最高价 | 收盘跌破此前10日最低价 |

三种策略都固定为每日收盘计算一次、下一交易日开盘模拟成交。它们共享板块过滤、
市场趋势宽度、流动性门槛、仓位上限、止损和交易成本模型。

## 决策链

1. **判断市场环境**
   - 计算候选池中收盘价高于慢速均线的比例（趋势宽度）。
   - 宽度较高时为“进攻”，使用较高总仓位；中等时为“谨慎”，降低总仓位；
     较低时为“防守”，只保留约10%至15%的试探仓位，不再无条件全部清仓。
2. **选择板块**
   - 通过 Tushare 申万一级行业映射个股。
   - 按板块内个股综合趋势分与满足入选条件的比例排名，保留前三个板块。
3. **选择股票**
   - 按已选择的双均线、价格动量或通道突破规则计算个股分数。
   - 同时参考趋势强度、成交额和量能进行候选池内排序。
   - 剔除趋势为负、流动性不足和名称包含 ST 的股票。
   - 最多持有 5 只，同一行业最多 2 只。
4. **确定仓位**
   - 使用波动率倒数分配权重，波动大的股票权重更低。
   - 单只股票有仓位上限，组合总仓位受市场环境控制。
5. **生成动作**
   - `BUY`：新入选，或已有持仓明显低于目标仓位。
   - `SELL`：趋势仍成立，但持仓明显高于风险目标，只减仓不清零。
   - `CLOSE`：跌破慢速均线、触发止损、退出优选名单或市场进入防守。
   - 没有必要调整时生成“无操作”，不强行交易。

信号在收盘后确认，订单在下一交易日开盘价基础上加入滑点后模拟成交。交易费用包含
佣金最低收费、股票卖出印花税、滑点和 A 股 100 股整手约束。

## 每日工作流

首次使用：

1. 打开网页中的“中短期趋势组合驾驶舱”。
2. 设置候选池、至少一年的回测起点/终点、模拟盘起点和初始资金。
3. 点击“初始化并逐日历史推演”。这会重置同名虚拟账户，并自动依次处理模拟期
   每个交易日的回顾、分析、决策与复盘。

回测期结束后账户资金仍等于初始资金。模拟盘起点当天收盘产生第一批信号，下一交易日
开盘才可能发生第一笔模拟成交，从而避免使用尚未形成的收盘信号在当天开盘交易。

之后每天：

1. 保持前台服务运行；系统会在本地时间 18:00 后自动尝试一次。
2. 也可以在收盘数据更新后点击“更新今日数据”。
3. 查看市场状态、优选板块和下一交易日执行计划。
4. 第二天再次运行时，上一日计划按开盘价模拟成交。

调度逻辑属于前台启动进程，关闭窗口或按 `Ctrl+C` 后不会遗留后台任务。接口按交易日
幂等；自动运行和手动点击同一天也不会重复成交。异常会完整打印到命令行。

## 每日决策日志

模拟期的每一个交易日都会写入一份日志，包括没有成交的日期。日志固定包含：

1. **回顾**：昨日计划、今日实际成交、未成交标的、日收益和回撤。
2. **分析**：市场状态、趋势宽度、数据完整度、优选板块、候选股票和当前持仓。
3. **决策**：下一交易日的买入、减仓、平仓指令；没有指令时必须写明无操作原因。
4. **复盘**：把结果归类为数据、执行、策略、市场环境或正常，并记录证据和下一日关注点。

网页默认保留并可切换最近30个交易日的日志；每个账户对应的 UTF-8 JSON 文本账本
保存完整历史。每日复盘是
可审计的确定性诊断，不会因为单日结果直接改写策略或生成不可追踪的代码。

## 反思系统

除每日必写日志外，达到风险阈值的异常还会进入独立告警列表。异常不会直接改写策略，
而是记录诊断、证据和建议：

| 分类 | 说明 | 优先检查 |
|---|---|---|
| `DATA_INCOMPLETE` | 行情、停牌或行业分类缺失 | 数据源、复权、日期与字段 |
| `EXECUTION_SURPRISE` | 次日开盘相对信号价大幅跳空 | 公告、涨跌停和开盘偏离限制 |
| `STRATEGY_MISS` | 数据完整但组合发生异常日损失 | 信号失效、仓位和止损 |
| `REGIME_SHIFT` | 回撤或趋势宽度快速恶化 | 总仓位和防守版本 |
| `UNIVERSE_BIAS` | 股票池或历史长度不足 | 幸存者偏差、历史成分股 |
| `UNEXPECTED_RESULT` | 好得异常的样本外结果 | 未来函数、事后选股和过拟合 |

“收益异常好”同样需要反思；它经常比亏损更容易掩盖数据泄漏或选样偏差。

## 自动升级

系统使用冠军—挑战者机制。参数版本是代码中固定、可审计的规则，挑战者只能在影子
回放中运行，不会生成或执行任意代码。

自动晋级必须同时满足：

- 至少 20 个候选标的；
- 至少 504 个交易日；
- 样本外夏普比当前冠军高至少 0.15；
- 样本外最大回撤不能明显恶化；
- 样本外年化收益为正；
- 有足够的再平衡次数。

任何一项不足都记录为拒绝，不改变冠军。晋级也只改变模拟账户使用的参数版本，不会
突破“禁止真实交易”的边界。

## 当前局限

- 当前板块强弱是小候选池内排名，不是全市场行业轮动。
- 未处理逐日 ST 状态、历史上市/退市成分、涨跌停无法成交和停牌订单延期。
- Tushare 日线适合每日中短期研究，不提供真实券商成交确认。
- 历史回放结果不能直接视为未来收益预期。
